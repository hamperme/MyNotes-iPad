# 外部 PDF 导入（原生 iPad）

## 使用

- **从「文件」导入**：回到 MyNotes 笔记列表，点右上角「导入 PDF」，在系统文件选择器中选择 PDF。导入完成自动打开多页笔记。
- **从微信等其他 App 导入**：打开 PDF 附件，使用该 App 的「用其他应用打开」/「在其他 App 中打开」，选择 MyNotes；若分享列表折叠，可查看「更多」。不同微信版本的菜单名称和显示位置不同。若没有 MyNotes，先「存储到文件」，再使用上一条路径。
- 接收的是实际 PDF 文件，不是微信聊天链接、网页地址或图片。没有单独的分享扩展；系统通过 PDF 文档类型注册把文件交给应用的 `onOpenURL`。
- 翻页、加空白页仍在右下角；双指缩放/移动，画笔、双模式橡皮擦、套索仍操作独立笔迹层。PDF 页使用原始页面的裁剪尺寸和旋转方向，不能切换纸张模板；追加的空白页可以。
- 默认沿用“铺满屏幕”。需要看到整个 PDF 时，在书写设置选择“适合整页”。

## 数据与限制

- 获得 security-scoped 访问后，在后台协调读取，并逐字节复制到 Application Support/MyNotes/<note-id>/source.pdf；从不改写外部原件。临时来源撤回/删除不影响已经导入的笔记。
- 校验成功后移动临时目录，原子提交索引，最后发布新笔记。导入失败不新增笔记；索引写入失败会移除本次副本，不改已有笔记。
- `NoteRecord.sourcePDF` 和 `PageRecord.pdfPageIndex` 是新增可选字段；旧索引缺少字段时仍可读取。每页继续用独立稳定 UUID 和 `.drawing` 文件；重名导入创建独立笔记，不覆盖旧文件。
- PDFKit 按页显示原 PDF（保留其已有注释）；透明 PencilKit 位于其上。外层视口统一变换背景与笔迹；PDFView 本身不接受缩放/滚动手势。只缓存当前 PDFDocument。
- 暂限单个文件 **100 MiB、1000 页**，拒绝加密/损坏/非文件 URL、异常页尺寸。发生错误有明确提示。缺失原件时显示恢复提示，不自动删除笔迹。
- **不含批注 PDF 导出**、OCR、PDF 页面删除/重排、密码解锁或真实微信分享界面自动化。Issue #5 仍保留开放；50 页功能回归不等于大型文件内存/性能验收。
- 升级前保留完整数据备份。源码回滚脚本只恢复源码，不恢复 iPad 笔记；已经导入 PDF 后不要直接降级到不认识 PDF 元数据的旧 App 并继续保存，旧版可能丢弃新增字段。恢复应在备份副本上验证。

## 验证入口

`./scripts/check-editor.sh SIMULATOR_UUID` 在专用 iPad Simulator、独立测试 Bundle ID 上运行；不使用私人 PDF 或真实账号。测试覆盖旧编辑器回归、文档注册与文件选择入口、50 页原件/笔迹存储、旧索引、重复导入、损坏/加密拒绝、提交失败清理、裁剪/旋转几何及外部 URL 接收。

物理 iPad 上的微信实际菜单、外部文件提供器权限、Apple Pencil 批注和大文件性能，需要单独验收；见 TEST_PLAN 的实际运行结果，不能仅凭代码或 Simulator 勾选。
